# 한국에서 덜 쓰고 더 잘 사는 법

**전세부터 건강보험까지, 한국 생활의 큰 지출과 큰 손해를 줄이는 60가지 방법.**

월세와 통신비를 줄이고 싶을 때, 전세 계약이 불안할 때, 퇴사 후 무엇부터 해야 할지 막막할 때 찾아보는 한국어 생활 가이드입니다. 건강·주거·금융·일·복지·돌봄을 **실행 방법 → 비용과 시간 → 기대효과 → 적용 조건 → 공식 출처** 순서로 정리했습니다.

**10개 주제 · 60개 핵심 항목 · 공식 출처 링크 · 2026년 10월 9일 기준 초판**

## 이 가이드가 판단하는 방법

**비용과 효과를 같이 봅니다.** 무료 신청이라도 자격·대기·자부담이 있을 수 있고, 할인율이 높아도 실제 총지출이 늘면 이득이 아닐 수 있습니다. 시간을 쓰는 것도 비용입니다.

**근거 유형을 구분합니다.** 공식 지침, 제도·법령, 실용 판단을 따로 표시합니다. 공식 제도가 존재한다는 사실과 내가 대상자로 승인된다는 것은 다릅니다. `먼저 / 해당할 때 / 꾸준히`는 편집상 실행 순서이며 과학적으로 산출한 효과 순위가 아닙니다.

**확인 가능한 출처를 붙입니다.** 한국의 운영기관·법령·공식 안내를 우선하고 건강 분야는 WHO 지침도 참고합니다. 시간은 별도 설명이 없으면 작성상 추정치입니다. 출처 확인일은 자료의 게시일·시행일과 다르며 신청 당일의 요건 확인을 대신하지 않습니다.

더 자세한 읽는 방법은 [서문](INTRO.ko.md)에 있습니다.

## 인터넷 없이 읽기

저장소를 ZIP으로 내려받아 압축을 푼 뒤 **index.html**을 브라우저로 열면 한글 검색과 주제·실행 시점 필터를 쓸 수 있습니다. 별도 설치, 서버, 회원가입은 필요 없습니다. 출처 링크를 여는 데에는 인터넷이 필요합니다. GitHub의 파일 화면에서는 HTML이 실행되지 않으므로 내려받아 여세요.

## 파일 구성과 수정

| 파일 | 용도 |
| --- | --- |
| `GUIDE.ko.md` | 60개 항목 통합 본문 |
| `book/` | 주제별 Markdown 10개 |
| `index.html` | 검색 가능한 오프라인 읽기 파일 |
| `data/guide.json` | 재사용·수정용 항목 원본 |
| `SOURCES.md` | 항목별 출처와 확인일 |
| `INTRO.ko.md` | 서문 원본 |
| `tools/build.mjs` | 본문·장별 파일·출처·HTML 생성 |
| `CONTRIBUTING.md` | 수정과 근거 확인 방법 |

내용을 고친 뒤 Node.js가 설치된 환경에서 다음을 실행하면 배포 파일이 함께 갱신됩니다. 외부 패키지는 필요 없습니다.

```sh
node tools/build.mjs
```
